# 📚 Documentação do Compiler Edu Game

Bem-vindo à central de documentação do **Compiler Edu Game**, um jogo educativo desenvolvido como **Atividade Curricular de Extensão (AEX)** do curso de Ciência da Computação da **UENP**.

Esta pasta contém toda a documentação técnica, pedagógica, de engenharia de software e de gestão do projeto para orientar desenvolvedores, professores e estudantes.

## 🎯 Como Utilizar esta Documentação

1. **Cada Grupo (Grupos 1 a 6):** Deve copiar o [Template de Documentação de Fase](templates/template_documentacao_fase.md) e salvar em `docs/fases/faseX_nome.md` para documentar sua fase com artefatos de Engenharia de Software.
2. **Novos Integrantes:** Comecem lendo o [README principal do repositório](../README.md) e em seguida a [Engenharia de Software](engenharia_software.md) e o [Manual das Equipes](manual_equipes.md).
3. **Desenvolvimento de Fases:** Consultem a [Arquitetura Técnica](arquitetura.md) para garantir que sua cena e scripts sigam os padrões globais no Godot.
4. **Aplicação com a Comunidade:** Utilizem o [Guia de Evidências AEX](aex_evidencias.md) durante as oficinas e testes externos para registrar os resultados da extensão.

---

## ✏️ Mantendo a Documentação Atualizada

- Sempre que alterar uma mecânica ou funcionalidade na fase, atualize o documento de Engenharia da Fase em `docs/fases/faseX_nome.md`.
- Ao realizar alterações na arquitetura global, atualize o arquivo [arquitetura.md](arquitetura.md).
