## 1. 🎯 Descrição Geral e Objetivos Pedagógicos

### 1.1 Visão Geral da Fase
O **Reino dos Tokens** é a fase introdutória do *Compiler Edu Game*. O jogador explora o cenário coletando e identificando blocos de código e caracteres, aprendendo a distinguir palavras-chave, identificadores, constantes e símbolos especiais.

### 1.2 Conceito de Compiladores Abordado
- **Análise Léxica (Scanning/Lexing)**: Primeira etapa do compilador.
- **Categorias de Tokens**: Palavras reservadas (`int`, `float`, `if`, `while`), Identificadores (`x`, `soma`), Operadores (`+`, `=`, `*`), Delimitadores (`;`, `(`, `)`), Literais numéricos e constantes.
