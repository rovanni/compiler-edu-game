## 1. 🎯 Descrição Geral e Objetivos Pedagógicos

### 1.1 Visão Geral da Fase
Na **Floresta AST**, o jogador aprende a estrutura hierárquica das linguagens de programação, construindo e navegando por árvores sintáticas para avaliar expressões aritméticas e lógicas.

### 1.2 Conceito de Compiladores Abordado
- **Árvore Sintática Abstrata (Abstract Syntax Tree - AST)**: Representação estruturada em árvore do código fonte.
- **Nós e Folhas**: Operadores como nós pais e operandos/identificadores como folhas.
- **Precedência e Ordem de Avaliação**: Resolução de subárvores e percurso em profundidade (ordem pós-fixa / in-fixa).
