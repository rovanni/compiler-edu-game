## 1. 🎯 Descrição Geral e Objetivos Pedagógicos

### 1.1 Visão Geral da Fase
Na **Fortaleza Sintática**, o jogador assume a defesa de um castelo utilizando canhões para destruir balões que carregam trechos de código com erros sintáticos ou proteger comandos com gramática perfeita.

### 1.2 Conceito de Compiladores Abordado
- **Erros Sintáticos**: Estruturas gramaticais que violam as regras da linguagem:
  - Falta de delimitadores ou ponto e vírgula (`;`).
  - Parênteses e chaves não balanceados (`if (x > 0 {`).
  - Expressões incompletas (`var a = 10 + ;`).
  - Atribuições a palavras reservadas ou comandos fora de contexto.
- **Diagnóstico do Compilador**: Mensagens de erro com número da linha e token esperado.
